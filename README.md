# P1XY Bots

Telegram CRM-бот для мелкого бизнеса: добавление клиентов, роли операторов.

## Стек

- Python 3 + [aiogram 3](https://docs.aiogram.dev/)
- SQLite (через `aiosqlite`)
- `uv` — управление зависимостями и venv
- FSM (Finite State Machine) для диалоговых сценариев

## Архитектура

```
app/
  config/       — настройки, работа с БД (db.py, settings.py)
  utils/        — валидаторы, middleware
main.py         — точка входа, хендлеры
```

Принципы, которых придерживаемся:
- **YAGNI** — не тащим инфраструктуру, пока не понадобилась
- **Fail Fast** — конфиг падает сразу и понятно, если что-то не так
- **Single Responsibility** — каждый модуль отвечает за одну вещь

## Запуск

```bash
uv sync
cp .env.example .env   # заполнить BOT_TOKEN и ADMIN_ID
uv run main.py
```
